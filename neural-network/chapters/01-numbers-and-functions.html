Numbers & Functions

Where we start: what a number actually is, what a function actually does, and why the exponential and logarithm are about to be everywhere.

Why we start here

A neural network is a long stack of arithmetic — multiplications, additions, and a handful of nonlinear functions — that together compute a useful thing. To understand it, we don't need anything mystical. We need to be very comfortable with three plain ideas: numbers, functions, and the way functions combine. This chapter is the absolute foundation. If you remember it cold, every chapter that follows will feel familiar.

Intuition

Think of a neural network as a Rube Goldberg machine. Each piece is small and easy. The reason the whole thing is impressive is that there are a lot of pieces, hooked together in a clever order. We're going to build the smallest pieces first.

Numbers

We will work almost entirely with real numbers: things like $0$, $-3$, $\tfrac{1}{2}$, $\sqrt{2}$, $\pi$. The set of all real numbers is written $\mathbb{R}$. You can imagine $\mathbb{R}$ as the unbroken number line stretching from $-\infty$ to $+\infty$.

Two facts about real numbers will matter constantly:

  • They are ordered. Given any two of them, one is larger or they are equal. This is what lets us speak of "going up" or "going down."
  • They are continuous. Between any two real numbers there is another real number. We can talk about arbitrarily small differences. This is what makes derivatives meaningful in Chapter 3.

We will rarely need complex numbers, irrationality theorems, or anything more exotic. Treat $\mathbb{R}$ as the playground.

Variables

A variable is a name we attach to a number whose value we either don't know yet or want to leave general. In algebra textbooks the variable is usually $x$. In machine learning it might be $w$ for "weight," $b$ for "bias," $\theta$ for "the parameters," or $\eta$ for "the learning rate." The letter is just a label. What matters is whether the value is allowed to change and what it stands for.

It is useful to distinguish three roles a variable can play:

  • Inputs — what we feed into a function. Often called $x$.
  • Outputs — what comes out. Often called $y$ or $\hat{y}$.
  • Parameters — settings inside a function that we tune. Often called $w$ and $b$.

A neural network is, ultimately, a function with hundreds of millions of parameters. We don't have to memorize them. We just have to know they exist and that we can adjust them.

A note on $\theta$

$\theta$ (the Greek letter "theta") is shorthand for all the parameters of a model bundled together. A network has many individual weights and biases — $w_1, w_2, \ldots, b_1, b_2, \ldots$ — but written as one symbol they become $\theta$.

When we write $L(\theta)$ later, that one $\theta$ is hiding millions of numbers. It's just a way to keep equations short.

Functions

A function is a rule that takes an input and returns exactly one output. We write $f : A \to B$ to mean $f$ accepts inputs from set $A$ and produces outputs in set $B$. For most of this site, $A$ and $B$ are $\mathbb{R}$ (single numbers) or $\mathbb{R}^n$ (lists of $n$ numbers — see Chapter 2).

Three ways to specify a function — each one is the same idea expressed differently:

  1. By formula. $f(x) = 3x + 2$.
  2. By table. A list of input/output pairs.
  3. By picture. The graph: a curve drawn in a plane where the horizontal axis is the input and the vertical axis is the output.

The picture is how we will build intuition; the formula is how we will compute; the table will appear when we do worked numerical examples.

Composing functions

If $f$ takes the output of $g$ as its input, we say "$f$ composed with $g$," written

$$ (f \circ g)(x) \;=\; f\bigl(g(x)\bigr). $$

This is innocent in symbols and enormous in consequence. A neural network is nothing but a long chain of compositions: layer one feeds layer two feeds layer three, and so on. The chain rule of calculus (Chapter 3) is the tool that lets us take a derivative through that chain. Memorize the shape of composition now: an outer function applied to the result of an inner function.

Quick example: let $g(x) = x + 1$ and $f(u) = u^2$. Then

$$ (f \circ g)(x) = f(x+1) = (x+1)^2 = x^2 + 2x + 1. $$

Notice the order: $g$ runs first, $f$ runs second. The notation $f \circ g$ reads right to left, like a stack of operations.

The exponential function

Out of all the functions we will meet, two non-polynomial ones do the heavy lifting throughout machine learning: the exponential and its inverse, the logarithm. We need to be friends with both before going further.

The exponential function is written $\exp(x)$ or $e^x$, where $e \approx 2.71828\ldots$ is a special constant chosen for a reason we will appreciate in Chapter 3. For now, take these properties as the definition:

  • $e^0 = 1.$
  • $e^{a+b} = e^a \cdot e^b.$ Adding in the exponent multiplies the values.
  • $e^{-x} = 1 / e^x.$ Negation in the exponent flips to a reciprocal.
  • $e^x > 0$ for every real $x$. The exponential is always positive.
  • $e^x$ grows extremely fast as $x$ increases and shrinks toward $0$ as $x$ decreases.

Why does it appear so often? Two reasons we will revisit:

  • It is the unique function whose rate of change equals itself. Its derivative is $e^x$. (Chapter 3.)
  • It turns sums into products and back, which is exactly what you need to convert "log probabilities of independent things" into "probability of the joint thing." (Chapter 5.)

The logarithm

The logarithm $\ln(x)$ — sometimes written $\log(x)$ in machine-learning code — is the inverse of the exponential. By definition,

$$ \ln(e^x) = x, \qquad e^{\ln(x)} = x \;\;\text{for } x > 0. $$

Properties that follow immediately, and that we will use constantly:

  • $\ln(1) = 0$ (because $e^0 = 1$).
  • $\ln(ab) = \ln(a) + \ln(b)$. Logs turn products into sums.
  • $\ln(a/b) = \ln(a) - \ln(b)$.
  • $\ln(a^k) = k \ln(a)$.
  • $\ln(x)$ is defined only for $x > 0$. It goes to $-\infty$ as $x \to 0^+$ and slowly upward as $x \to \infty$.
Why we use logs in machine learning

Probabilities are numbers between $0$ and $1$ — they are easy to multiply but tend to underflow to zero on a computer once you multiply enough of them. Working with $\ln(\text{probability})$ instead turns a long product into a long sum, which is numerically stable and algebraically friendly. This is the entire reason "log-likelihoods" and "cross-entropy" are written with logs in Chapter 5.

A small zoo of functions you will meet

Beyond plain lines and parabolas, here is the cast that returns later in this site:

  • Affine: $f(x) = wx + b$. The basic neuron before any nonlinearity. Two parameters: a slope $w$ and an offset $b$. (High-school algebra writes this as $y = mx + b$. We use $w$ because in a neural network this exact slope is called the weight: the number that gets multiplied by the input. Same number, ML name.)
  • Sigmoid: $\sigma(x) = \dfrac{1}{1 + e^{-x}}$. Squashes any real input into the interval $(0,1)$. Built from $e^x$.
  • ReLU: $\mathrm{ReLU}(x) = \max(0, x)$. Zero for negative inputs, identity for positive ones. Looks like a hockey stick.
  • Quadratic: $f(x) = x^2$. Used everywhere as a "how wrong are we?" measure.

We will meet these in detail in Chapter 6. For now, just notice: every one of them is a recipe that turns a number into another number.

Check yourself

Before moving on, you should be able to answer these without looking back:

  1. If $f(x) = 2x + 5$ and $g(x) = x - 3$, what is $f(g(2))$?
  2. What is $\ln(e^4)$?
  3. What is $e^{\ln(7)}$?
  4. Without a calculator, is $e^{-2}$ closer to $0$, $1$, or $7$?
  5. Why does $\ln(\text{negative number})$ not exist in the real numbers?

Answers, in order: $f(g(2)) = f(-1) = 3$; $\ln(e^4) = 4$; $e^{\ln(7)} = 7$; $e^{-2} \approx 0.135$, closer to $0$; because $e^x$ is always positive, no real $x$ makes $e^x$ negative, so the inverse is undefined there.
