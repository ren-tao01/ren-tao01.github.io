Recurrent Networks

An MLP that has memory. We unroll it through time, derive backprop-through-time, meet the vanishing gradient, and read the LSTM cell.

Why we need a different architecture

Many tasks process sequences: sentences, audio waveforms, time-series sensor data, video frames. The key fact is that the input length varies and order matters. An MLP with a fixed-size input vector cannot handle a sequence of unknown length without awkward padding. A CNN is better, but its receptive field is fixed.

A recurrent neural network (RNN) processes the sequence one step at a time, carrying a small hidden state from one step to the next. Conceptually:

"Read a token. Update memory. Repeat."

The vanilla RNN

At time $t$, given input $\mathbf{x}_t$ and previous hidden state $\mathbf{h}_{t-1}$, the RNN computes

$$ \mathbf{h}_t \;=\; \tanh\!\bigl(\mathbf{W}_{xh}\, \mathbf{x}_t + \mathbf{W}_{hh}\, \mathbf{h}_{t-1} + \mathbf{b}_h\bigr), $$

and optionally produces an output $\mathbf{y}_t = \mathbf{W}_{hy}\mathbf{h}_t + \mathbf{b}_y$ at each step. The matrices $\mathbf{W}_{xh}, \mathbf{W}_{hh}, \mathbf{W}_{hy}$ and the biases are shared across all time steps — exactly the parameter-sharing trick that made CNNs efficient.

Backpropagation through time

Once unrolled, an RNN is just a (long, peculiar) feed-forward network in which many layers share the same weights. Backpropagation applies as usual; we call it backpropagation through time (BPTT).

Two consequences:

  • The gradient with respect to a shared weight is the sum of contributions across all time steps where that weight appears.
  • To compute the gradient at step $t$, we need the activations from every earlier step. So memory cost grows with sequence length.

For very long sequences we use truncated BPTT: backpropagate only the last $K$ steps and treat earlier hidden states as fixed inputs. Cheaper, but also blind to long-range dependencies beyond $K$.

The vanishing-gradient problem

Apply the chain rule across $T$ time steps. The gradient of the loss with respect to $\mathbf{h}_0$ involves a product of $T$ Jacobians of the recurrence, each of the form

$$ \frac{\partial \mathbf{h}_{t}}{\partial \mathbf{h}_{t-1}} \;=\; \mathrm{diag}\!\bigl(\tanh'(\mathbf{z}_t)\bigr) \cdot \mathbf{W}_{hh}. $$

If the largest singular value of this matrix is below $1$, repeated multiplication shrinks the gradient toward zero — the vanishing gradient. If it is above $1$, the gradient explodes. Either way, learning long-range dependencies is hopeless: the signal from step $T$ can no longer reliably steer the weights at step $1$.

Gradient clipping (rescaling whenever the norm exceeds a threshold) handles explosions. Vanishing is harder; it requires a different recurrence.

The LSTM

The long short-term memory cell (Hochreiter & Schmidhuber, 1997) replaces the simple tanh recurrence with a gated mechanism that lets gradients flow more easily across time. It carries two state vectors: a cell state $\mathbf{c}_t$ and a hidden state $\mathbf{h}_t$. At each step:

$$ \begin{aligned} \mathbf{f}_t &= \sigma\!\bigl(\mathbf{W}_f [\mathbf{h}_{t-1}; \mathbf{x}_t] + \mathbf{b}_f\bigr) && \text{forget gate} \\ \mathbf{i}_t &= \sigma\!\bigl(\mathbf{W}_i [\mathbf{h}_{t-1}; \mathbf{x}_t] + \mathbf{b}_i\bigr) && \text{input gate} \\ \tilde{\mathbf{c}}_t &= \tanh\!\bigl(\mathbf{W}_c [\mathbf{h}_{t-1}; \mathbf{x}_t] + \mathbf{b}_c\bigr) && \text{candidate cell update} \\ \mathbf{c}_t &= \mathbf{f}_t \odot \mathbf{c}_{t-1} + \mathbf{i}_t \odot \tilde{\mathbf{c}}_t && \text{updated cell state} \\ \mathbf{o}_t &= \sigma\!\bigl(\mathbf{W}_o [\mathbf{h}_{t-1}; \mathbf{x}_t] + \mathbf{b}_o\bigr) && \text{output gate} \\ \mathbf{h}_t &= \mathbf{o}_t \odot \tanh(\mathbf{c}_t) \end{aligned} $$

The semicolon means stacking $\mathbf{h}_{t-1}$ and $\mathbf{x}_t$ into a single column. Each gate is a sigmoid output, so its values lie in $(0,1)$ and act as element-wise on/off switches.

The crucial line is the cell-state update: $\mathbf{c}_t = \mathbf{f}_t \odot \mathbf{c}_{t-1} + \mathbf{i}_t \odot \tilde{\mathbf{c}}_t.$ When the forget gate is close to $1$, the cell state passes through almost unchanged. The gradient of $\mathbf{c}_t$ with respect to $\mathbf{c}_{t-1}$ is then approximately the identity, and gradients can flow across many time steps without shrinking. That is the LSTM's whole reason for existing.

The GRU, briefly

The gated recurrent unit (Cho et al., 2014) is a simpler cousin: it merges the forget and input gates into a single update gate, and merges the cell state with the hidden state. Fewer parameters, often comparable performance. The takeaway: gating is the important idea; the exact wiring is a matter of taste.

Common usage patterns

  • Many-to-one: feed a sequence in, take the final hidden state, classify (e.g. sentiment of a sentence).
  • Many-to-many (aligned): produce an output at every step (e.g. part-of-speech tagging).
  • Encoder-decoder (sequence to sequence): one RNN compresses a sequence into a single vector; another RNN expands that vector into a target sequence (e.g. machine translation in 2014–2016).
  • Bidirectional RNN: run two RNNs over the sequence — one left-to-right, one right-to-left — and concatenate. Each step's representation now sees both past and future context.

Why we'll soon need attention

Encoder-decoder RNNs work when sequences are short, but they squeeze the entire input into a single fixed-size vector that the decoder must use to produce every output token. For long inputs (a paragraph translated to another language), the bottleneck strangles the model.

The fix, in 2015, was attention: instead of compressing, let the decoder reach back and look at all encoder states each time it produces a new output, and learn to weight which ones to focus on. That single idea — attention — soon proved so powerful that recurrence itself was no longer needed. We meet it in Chapter 13.
